# 多语言与机器文本规范 / I18N / 多言語規約

ReferenceCity 继承 UrbanPlanningLab 的三语原则：中文为中国规划语义的源文本，英文与日文为正式镜像；机器标识符保持英文稳定值。

## 1. 人类可读名称

需要面向研究者展示的对象可使用：

```json
{
  "name": {
    "zh-CN": "中央区",
    "en": "Central District",
    "ja": "中央区"
  }
}
```

但对象永久 ID 只保留一个：

```text
RC:DISTRICT:001
```

## 2. 不本地化的内容

以下内容禁止因语言改变：

- IDs；
- JSON keys；
- Schema `$id`；
- event type；
- error code；
- enum stable values；
- hash / signature；
- file-format identifiers。

例如：

```text
APPROVE
VERSION_CONFLICT
HASH_MISMATCH
```

三语 UI 可以显示本地化标签，但底层值保持一致。

## 3. 中国制度术语

ReferenceCity 是实验环境。涉及“国土空间规划、三区三线、详细规划、审批”等术语时：

- 中文描述可采用中国规划语境；
- 英文应说明其 Chinese planning context；
- 日文不得默认映射成日本法制度中看似相近但法律含义不同的概念；
- 机器 Schema 优先使用中性的功能性英文名称。

## 4. 三语场景名称

Scenario 必须具有三语名称字段；长篇说明至少中文完整，稳定版本前补齐英文与日文。

```yaml
name:
  zh-CN: 无权限主体修改
  en: Unauthorized actor modification
  ja: 権限を持たない主体による変更
```

## 5. 翻译同步

- README 与 Roadmap 始终维护三语镜像；
- Schema 说明以英文机器语义为中心，可添加三语 description；
- Ground Truth 本身不按语言复制，避免三份“标准答案”漂移；
- 术语优先引用 UrbanPlanningLab 的共享术语表。

## 6. 编码

所有文本文件统一 UTF-8。文件换行、日期和数值格式应适合跨平台自动处理。
