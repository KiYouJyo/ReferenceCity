# ReferenceCity ロードマップ

> 中国語版 `ROADMAP.md` を原文とする日本語ミラーです。

## Phase 1 — 国土空間トラストチェーン研究用ベンチマーク都市

### Phase 1A：文書、Schema、最小骨格

大規模な都市を描く前に、研究者と機械の双方が ReferenceCity を同じ意味で理解できる状態を作ります。

- [x] 三言語プロジェクト概要；
- [x] UrbanPlanningLab との責務境界；
- [x] コアデータ領域とベンチマークシナリオ概念；
- [ ] Spatial / Planning / Governance / Event / Ground Truth Schema v0.1；
- [ ] 安定 ID 規則；
- [ ] CRS、単位、日時、版管理規約；
- [ ] provenance / sensitivity manifest。

### Phase 1B：人間が確認可能なコア都市 v0.1

1 都市、3 区レベル単位、6–10 下位行政単位、50–100 区画、100–300 建築物・施設等、基本道路・水系、および内部整合した現況土地利用・計画規制データを持つ小規模都市を構築します。

すべての主要オブジェクトに安定 ID を付与し、幾何関係を人間が確認できるようにします。現実都市の精密座標や機微データは再現せず、生成パラメータ、手動修正、乱数シードを追跡可能にします。

### Phase 1C：計画ガバナンスモデル v0.1

計画作成機関、承認主体、市・区レベルの管理ロール、申請主体、権限マトリクス、Plan / PlanVersion / PlanningDocument / Approval、およびライフサイクル状態機械を構築します。

初期ライフサイクル：

```text
Draft → Submitted → Reviewed → Approved → Effective
                                      ↓
                                  Amendment
                                      ↓
                               New Effective Version
```

### Phase 1D：Benchmark Scenarios v0.1

最低限、正常登録、合法的版更新、正常承認、権限外変更、承認済み文書改ざん、土地利用競合、規制境界横断、必要主体/署名欠落、履歴版検証、競合更新を用意します。

各シナリオは機械可読な `input` と `expected` の両方を持たなければなりません。

### Phase 1E：Trust Chain 接続と回帰

- 実装に依存しない安定した入力を提供する；
- チェーン実行結果と Ground Truth を比較する；
- ReferenceCity v1.0 を固定ベンチマークとして公開する；
- 後続版のチェーンでも同じベンチマークを再実行する；
- 正しさ検証と性能試験を分離する。

### Phase 1 完了条件

Schema が安定し、コア都市の完全な export/import が可能で、10 以上の標準シナリオに機械可読 Ground Truth があり、計画ライフサイクルをトラストチェーン上で end-to-end 実行でき、主要シナリオが決定論的に再現でき、出典・機微性不明のデータが存在しない状態で ReferenceCity v1.0 を公開します。

## Phase 2 — 現実の公開データとの互換性

合成コアの Ground Truth を汚染せず、現実 GIS 公開データを同一モデルへマッピングできるか検証する fixtures を追加します。

## Phase 3 — 計画研究向け形態拡張

伝統街路、単位大院、高層閉鎖型住宅団地、小街区型開放コミュニティ、城中村、工業地区、TOD、新城、都市農村境界部、村落等の形態プロトタイプを段階的に追加します。

## Phase 4 — 研究実験環境

統制実験、都市更新状態遷移、人居形態指標、中日比較研究等を支援します。形態生成ルールに研究上の予定結論を埋め込んではなりません。

## Phase 5 — Scale / Stress Benchmarks

10K、100K、1M 以上の独立データセットを生成し、性能・拡張性・分散処理を検証します。ストレスデータは人間が検証する ReferenceCity コア都市には含めません。
