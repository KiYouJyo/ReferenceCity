# 数据来源、安全与合规政策

## 1. 核心原则

ReferenceCity 的存在目的之一，就是让国土空间可信链研究**不依赖真实政府内部、敏感或涉密空间数据**。

核心城市优先使用完全合成数据。任何现实数据进入仓库前，都必须证明其公开性、许可范围和再分发条件。

## 2. 数据来源类型

所有数据集必须声明以下类型之一：

- `SYNTHETIC`：由本项目规则/生成器构造；
- `PUBLIC_REAL`：来自合法公开来源的现实数据；
- `DERIVED`：由其他合法数据计算、概化或转换得到；
- `MANUAL_ANNOTATION`：研究者人工创建或标注。

禁止使用 `UNKNOWN` 作为正式发布版本中的来源状态。

## 3. 数据清单要求

每个数据包至少记录：

```text
dataset_id
title
source_type
source_name
source_url_or_reference
license
redistribution_allowed
created_or_retrieved_at
processing_history
spatial_scope
crs
sensitivity
notes
```

## 4. 敏感性等级（项目内部数据治理标签）

以下标签仅用于本项目数据管理，不替代任何法律上的定密或官方分类：

- `OPEN`：可公开、可按许可证使用；
- `SYNTHETIC_SAFE`：完全合成，不指向现实敏感地点；
- `REVIEW_REQUIRED`：公开性、许可或空间敏感性需要人工复核；
- `DO_NOT_COMMIT`：不得提交到公开仓库。

任何疑似敏感、高精度且来源/许可不明确的数据，默认 `DO_NOT_COMMIT`。

## 5. 明确禁止

公开仓库不得提交：

- 政府内部或未经公开授权的国土空间数据库；
- 涉密资料或明显受限的高精度测绘/地理信息；
- 来源不明的规划数据库、管线、权属等敏感数据；
- 许可证禁止再分发的数据副本；
- 为“增加真实性”而从现实敏感区域直接复制的精确空间结构；
- 非研究必要的个人敏感信息。

## 6. 合成城市规则

ReferenceCity 核心：

- 不使用真实城市名称作为默认行政单元；
- 不声称空间对象对应现实宗地或建筑；
- 不以现实敏感坐标的微扰版本冒充 synthetic；
- 生成规则、参数和随机种子应可追溯；
- 可借鉴一般性的中国城市空间结构与规划逻辑，但不能复制受限数据。

## 7. 上链边界

即使将来接触合法的真实规划数据，默认架构仍应支持：

```text
Off-chain authoritative data
        ↓ hash / version / identity / approval proof
On-chain trust record
```

不将“完整真实 GIS 数据永久复制到多节点”作为可信链的默认方案。

## 8. 现实公开数据

Phase 2 以后引入 OSM、公开规划成果等数据时：

- 单独存放或通过脚本下载，不与 Synthetic Core 混淆；
- 保留原许可证和 attribution；
- 能引用而无需再分发时，优先引用/生成下载脚本；
- 任何中国空间数据使用应额外检查适用的测绘地理信息、数据安全及平台许可要求。

## 9. 数据删除与修正

如果发现已提交的数据存在来源、许可、安全或隐私问题，应优先停止发布并移除当前版本；必要时进一步处理 Git 历史。变更原因应在不扩大敏感信息传播的前提下留下审计记录。
